# Smriti

A local memory and context engine for coding agents, designed to run on CPU and connect through the Model Context Protocol (MCP).

Smriti aims to find relevant code within a token budget and preserve facts across sessions. Facts are anchored to code so changes can flag stale memories; git-like history supports branches, merges, and rollback.

**Status:** Planning stage. The engine is not implemented yet. Existing tools address parts of this problem; Smriti's focus is combining retrieval with code-anchored, versioned memory.
