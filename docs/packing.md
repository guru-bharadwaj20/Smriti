# Context packing

Each symbol offers omit, name, signature/docstring, and full body. Multiple-choice dynamic programming is exact for independent additive costs. Methods include their class signature in each option, charging that dependency before selection. Shared dependencies may be charged more than once: this is conservative, not globally optimal dependency-aware packing. Parent full bodies suppress duplicated descendants after selection.

Bucketed budgets round costs upward and budget downward, ensuring safety at a possible quality cost. Greedy is a comparison baseline. The unconstrained DP is validated against exhaustive small instances; dependency deduplication and final tokenizer recount can change the selected objective. Tiktoken cl100k_base is the default; callers must choose the encoding used by their coding agent. ByteCounter is a UTF-8 byte upper bound, not a model tokenizer. Zero-budget output is empty.
